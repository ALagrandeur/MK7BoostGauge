Une seule fonction : contrôler l'aiguille de température du cluster via Motor_09 (0x647). Tous les paramètres ci-dessous configurent le mapping MAP (mbar) → byte coolant cluster.

🚦 Transmission — Input détecté

Lecture en direct de WBA_03 (0x394) sur le bus Cluster. Détermine si l'override Motor_09 est ACTIF ou silencieux.

État TX cluster WAITING
BOOST actif (gauge = pression turbo) : N S1 S2 S3 S4 S5 S6 M1 M2 M3 M4 M5 M6
TX silencieux (gauge = vraie temp via gateway) : P R D1 D2 D3 D4 D5 D6

🔌 CAN1 — branchement

CAN0 = toujours Cluster. CAN1 = bascule entre PCM (tap Powertrain, écoute seulement) ou Diagnostic (port OBD-II, écoute + transmission).

📡 PCM — Lecture en direct

Décodage passif des broadcasts Powertrain CAN. Aucune frame n'est transmise sur CAN1 (mode RX-only verrouillé par design).

MAP réelle — mbar
Coolant réel — °C
Haldex demande — %
RX can1 0

⚠️ Les IDs broadcast pour MAP / coolant / Haldex ne sont pas encore identifiés pour ton véhicule. Capture Powertrain CAN 10 s moteur tournant → envoie au dev pour décoder.

🛠️ OBD2 — Outil diagnostic

Requêtes UDS vers l'engine ECU via le port OBD-II. Nécessite LISTEN-ONLY désarmé.
